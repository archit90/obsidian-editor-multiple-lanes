# Editor Multiple Lanes: test catalogue

Deep test cases for Editor Multiple Lanes in a real Obsidian 1.15.0 (a throwaway sandbox: own Xvfb display, own
profile, own vault), driven over the DevTools protocol with real mouse, key, wheel and drag input where input
matters (`Input.dispatchMouseEvent` / `dispatchKeyEvent`, HTML5 drags intercepted and replayed with
`Input.dispatchDragEvent`), plus a second connection for popout windows and the Settings window. Every case also
fails on console errors and on card leaves left detached.

**Running.** Alone, in a fresh empty vault with only this plugin:

```sh
npm run build && e2e/sandbox.sh reset 3 && npm run e2e -- all    # or one group: npm run e2e -- ro [id-regex]
npm run e2e:restart                                              # LT-17, CO-07 (restarts the sandbox)
```

The suite makes its own fixtures (`e2e/fixtures.mjs`, written by `e2e/make-vault.mjs` before Obsidian starts and
put back before every case): notes A–D (`lanes-e2e/EL Alpha` … `EL Delta`), the notes A links to, a long note,
125 + 55 bulk notes, a PDF, an image, a canvas, a base, and the core plugins it uses (Workspaces among them).
Together with the other plugins, in another sandbox state. Each `OBS_PLUGINS` entry is a GitHub release
(`owner/repo[@version]`) or a folder holding a build (e.g. a clone of the plugin after `npm run build`):

```sh
e2e/sandbox.sh stop 3
OBS_SANDBOX_DIR=$PWD/.sandbox-together OBS_PLUGINS=archit90/obsidian-backlinks-full-view:SilentVoid13/Templater:archit90/obsidian-editor-outliner:liamcain/obsidian-calendar-plugin@1.5.10 \
  e2e/sandbox.sh reset 3
E2E_REQUIRE=backlinks-full-view,templater-obsidian,editor-outliner,calendar npm run e2e -- ct
```

**Needs.** A case that tests Lanes with another plugin lists it (`needs`) and is skipped without it (SKIP; a
failure with `E2E_REQUIRE`): CO-04, NE-20 (backlinks-full-view); RO-21, NE-23 (templater-obsidian); NE-24, PK-05
(editor-outliner); RO-25 (calendar); CO-01 (core Workspaces), RO-23 (core Bookmarks), RO-26 (core Daily notes).
Each contract with another plugin is also tested without it (group CT).

Status: **PASS**; **FAIL → fixed** (failed in a round, root cause fixed, passes now); **LIMIT** (behaves as a
documented limit); **SKIP** (needs a plugin that isn't there). Source: a `SPEC.md` section, or "common sense"
(where the spec is silent: what a careful Obsidian user expects, the same in a card as in a normal tab). The
evidence column is from the run that recorded the case's status; cases recorded before 2026-11-08 ran against a
large test vault's notes, their names differ from the fixtures'. Latest results: see "Runs" at the end.

Setup unless a case says otherwise: lanes only on, default layout `50, 50,50` (the runner's), all other settings
at their defaults, one lanes tab in the main window, left sidebar open.
